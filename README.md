# cherkasy-power-outages-calendar

Календар планових відключень світла для Черкаської області. Бот сам читає Telegram-канали з графіками, розпізнає картинку-годинник і оновлює файл календаря, на який можна підписатися на телефоні. Працює безкоштовно на GitHub Actions, комп'ютер вмикати не потрібно.

*English: a calendar feed of planned power outages in Cherkasy region. A bot reads the public Telegram channels, decodes the 24-hour schedule wheel image and publishes an `.ics` calendar you can subscribe to. Runs for free on GitHub Actions.*

## Підписка

| Черга | Посилання (iPhone / Mac) | Посилання (Google Календар та інші) |
|-------|--------------------------|--------------------------------------|
| 3.1 | `webcal://podmor.github.io/cherkasy-power-outages-calendar/3.1.ics` | `https://podmor.github.io/cherkasy-power-outages-calendar/3.1.ics` |

**iPhone:** Налаштування → Календар → Облікові записи → Додати обліковий запис → Інше → Додати підписаний календар → вставити посилання.
**Mac:** Календар → Файл → Нова підписка на календар.

Календар лише для читання. Події оновлюються самі: якщо графік змінився, час події міняється, а скасоване відключення зникає. Перед кожним відключенням є нагадування за 15 хвилин.

## Як це працює

1. Раз на 15 хвилин запускається `python -m outage_calendar`.
2. Бот читає публічну сторінку каналу `t.me/s/<канал>` (логін і ключі не потрібні).
3. Для кожного посту з картинкою береться дата з підпису («… на 8 жовтня»), а години відключень читаються з кольору секторів годинника: червоний означає, що світла немає. Картинки «ЗМІНИ» (яскраві сектори = зміни, бліді = без змін) читаються так само.
4. Для кожної дати діє остання картинка. Сусідні години об'єднуються в одну подію, також через північ.
5. Текстові повідомлення бота каналу («Енергоживлення увімкнуть в 09:00») використовуються як перевірка: якщо вони не збігаються з картинкою, у журналі з'являється попередження.
6. Якщо найновішу картинку прочитати не вдалося, запуск завершується помилкою, і GitHub надсилає лист власнику репозиторію.

Стан зберігається у `state/`, готові календарі у `docs/` (їх віддає GitHub Pages).

## Додати іншу чергу

У `config.json` додати рядок у `queues`: номер черги та назву її каналу (канали черг: `cherkasy_blackout_1`, `_2`, `_3`, `_4`, `_5`). Через кілька хвилин з'явиться `docs/<черга>.ics`.

```json
{ "queue": "1.1", "channel": "cherkasy_blackout_1" }
```

Мову подій змінює `"language"` (`"ru"` або `"uk"`), час нагадувань змінює `"alarm_minutes"`.

## Розробка

```
pip install -r requirements.txt pytest
python -m pytest
python -m outage_calendar
```

Тести містять скриншот реального поста каналу та сквозну перевірку на реальних постах.
